# プライバシーポリシー

最終更新日: 2026年11月2日

## はじめに

capsicum（以下「本アプリ」）は、Mastodon および Misskey に対応する Fediverse クライアントアプリです。本プライバシーポリシーでは、本アプリにおける情報の取り扱いについて説明します。

## 収集する情報

本アプリが端末内に保存する情報は以下の通りです。

- **アカウント認証情報** — ログイン時に取得するアクセストークンを、端末のセキュアストレージに保存します
- **アプリ設定** — 利用者が設定した各種設定値を端末内に保存します

これらの情報は端末内にのみ保存され、第三者に送信されることはありません。

## 外部との通信

本アプリは、以下のサーバーと通信を行います。

- **Mastodon / Misskey サーバー** — 利用者が接続先として選択したサーバーと通信します。通信内容はサーバーの API 仕様に準じます。各サーバーにおける情報の取り扱いについては、そのサーバーの運営者が定めるプライバシーポリシーをご確認ください
- **プッシュ通知リレーサーバー** — プッシュ通知機能を利用する場合、開発者が運営するリレーサーバー（`relay.capsicum.shrieker.net`）と通信します。リレーサーバーに送信される情報は以下の通りです
  - 端末のプッシュ通知トークン（APNs / FCM / WNS）
  - 接続先サーバーのドメイン名
  - アカウントの識別情報
  - 端末を区別するための識別子（本アプリが生成する乱数で、端末の固有 ID ではありません）

リレーサーバーは、Mastodon / Misskey サーバーから受信した通知を利用者の端末に転送する目的でのみこれらの情報を使用します。アクセストークンや投稿内容など、通知の転送に不要な情報はリレーサーバーに送信されません。

**通知の本文は、リレーサーバーでは読めません。**Mastodon / Misskey が暗号化した通知を、リレーサーバーは暗号化されたまま端末へ転送します。復号は端末内で行われ、復号に必要な鍵はリレーサーバーに送信されません。

### アプリ内課金に関する情報

アプリ内課金（サポーター／プッシュ通知リレーの利用権）をご利用の場合、リレーサーバーに以下の情報が送信されます。

- ストア（Apple App Store / Google Play）が発行する購入の識別子
- 購入した商品の識別子と、購入の状態（有効・支払い確認中・失効など）

リレーサーバーは、これらを Apple および Google の各サーバーに問い合わせて購入が有効かを確認し、**プッシュ通知の提供可否を判定する目的でのみ使用します。**クレジットカード番号などの決済情報は、**ストアが処理するため本アプリおよびリレーサーバーには一切渡りません。**

購入はストアのアカウントに紐づくもので、**Mastodon / Misskey のアカウントとは結び付けません。**

## 端末機能へのアクセス

本アプリは以下の端末機能を使用する場合があります。

- **カメラ / フォトライブラリ** — 投稿にメディアを添付する目的でのみ使用します。撮影・選択されたメディアは、利用者が接続先として選択したサーバーにアップロードされます

## 不具合の調査のために送信する情報

本アプリは、不具合の調査と修正のために、エラー監視サービス [Sentry](https://sentry.io/) へ次の情報を送信します。

- エラーやクラッシュの内容と、発生までの操作の記録
- 動作の計測値（起動にかかった時間など）
- アプリのバージョン、OS、端末の機種
- 本アプリが生成する識別子（端末やアカウントの固有 ID ではありません）
- 接続先サーバーのドメイン名とソフトウェアの種類
- プリセットサーバーの利用者かどうか、プッシュ通知リレーの利用権の状態

アクセストークン、パスワード、投稿の本文は、送信の前に取り除くようにしています。ユーザー名は、そのままの形では送信しません。購入の識別子は Sentry へ送信しません。

通信の性質上、Sentry は接続元の IP アドレスを受け取ることがあります。情報の取り扱いについては、[Sentry のプライバシーポリシー](https://sentry.io/privacy/)をご確認ください。

## 分析・広告

本アプリは、広告 SDK や、利用状況の分析・トラッキングのためのツールを使用しません。

## 子どものプライバシー

本アプリは、13歳未満の子どもから意図的に個人情報を収集することはありません。

## 変更について

本プライバシーポリシーは変更されることがあります。変更があった場合は、本ページを更新します。
